# PRD：网页构建与展示（子任务 3/4）

依赖：compute-index。下游：deploy。

## 要做什么

- 从 CSV + 计算结果生成网页。渲染两阶段（D10/D14）：
  - **阶段一（先做，验证管线）**：极简**分块证据页**——成都防护参考，分块并列：①四川官方分级（月度/区域/时效）②南方片流感趋势（环比箭头）③全国其他病原趋势 ④儿童分龄前三 ⑤防护建议。每块标覆盖周次/月份、来源发布日、数据状态。**不做合成总分**。
  - **阶段二（后迭代）**：各块展开趋势图（本年度曲线 + 往年同期对比线）+ 全 11 病原表 + 可切换查询其他省市（有当地周报显示当地/只有省级标"省级参考"/只有片区标"区域背景"/无数据标"未取得当地监测数据"，不显示成低风险）。
- 纯静态；**GitHub Pages 版可用 fetch 外部 JSON，本地版须把数据内联进 HTML**（保证 file:// 双击离线可打开，不被 CORS 拦截）。

## 约束

- 首屏结论优先但不合成单一风险分（D14）。
- 口径标注与数据状态在界面显著位置，不可省（缺=不显示 0，旧=不伪装最新，官方分级缺=不默认绿）。
- 分享友好、移动端可读。

## 验收标准（可独立验证）

- [ ] 阶段一分块证据页本地打开显示真实最新数据，各块口径/状态齐全，无合成总分。
- [ ] 本地 HTML 用 file:// 双击能离线打开（数据内联，无 fetch 报错/白屏）。
- [ ] 手机浏览器排版正常。
- [ ] 阶段二趋势图显示本年度曲线叠加往年同期对比线；数据缺失周次为断点/标注，不画假数据。
- [ ] 其他省市查询按当地数据实际覆盖分级展示，无数据不伪装低风险。
