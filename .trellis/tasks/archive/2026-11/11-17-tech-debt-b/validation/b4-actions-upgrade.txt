## 5. 破坏性变更核验（README/CHANGELOG 原文摘录）
checkout v6: 'persist-credentials now stores credentials in a separate file under $RUNNER_TEMP instead of directly in .git/config' + 'No workflow changes required - git fetch, git push, etc. continue to work automatically' + Docker container action 才需 runner>=v2.329.0
本仓库的 git push 走 shell step（weekly.yml 的 Commit data back），不是 Docker container action → 不受影响
checkout v7: 新增 pull_request_target / workflow_run 下阻止 fork PR checkout（本仓库仅 schedule + workflow_dispatch → 无关）
setup-python v6/v7: 新增 mirror/mirror-token/cache-dependency-path 等可选输入，python-version 语义不变
upload-pages-artifact v5: 'Update upload-artifact action to version 7 + add include-hidden-files input'；path 输入与默认 artifact 名 github-pages 不变
deploy-pages v5: 轮询退避/抖动改进；artifact_name 默认 github-pages、输出 page_url 不变
