# A1b 南方片流感同期对比展示

## Goal

承接 A1a 历史数据，规划南方片同周历年对比展示、环比相邻周守卫及过时占位文案替换；完成缺口分析、设计与实施计划、成稿评审后等待用户实施批准。

## 状态与授权

2026-11-12 用户仅授权建立任务和规划，未批准实施。前置 A1a 已归档，已有 2023W1–2026W44 共 200 周南方片数据。当前为需求草案，待缺口分析、成稿、评审、用户批准。

## Requirements

- 替换同期占位卡片和过时标签，提供南方片历史同期对比；修复环比相邻周与有效值判断。
- 数据仅来自 data/flu_south.csv，不混全国 FluNet/哨点数据；指数标相对强度，不输出百分位风险、感染概率或合成总分。
- 内联 HTML/SVG，零外部资源依赖、无 JS/fetch，file:// 可用。
- 不改抓取器、计算管线、CSV、workflow，不重做其他卡片或全站美化。
- 运行时代码写域 src/build_site.py；允许本任务规划/验证文件及 README 新卡片使用说明，路径在成稿中明确。

## Acceptance Criteria

- [ ] 当前数据年度与历史年度同周曲线明确标注地区、指标、年份、周次和来源。
- [ ] 仅最新周与上一自然周均有有效指数才显示方向；缺周或无效值不借用更早周、不当作零。
- [ ] 空集、单点、全零、失败行、缺周、重复周、非法值和 ISO 第 53 周有可测试的规则。
- [ ] 当前年度以最新数据的 ISO 年为锚，不以电脑年份把旧数据冒充最新。
- [ ] 历史年份选择、未来周显示范围、统一坐标轴、图例和同周数值可读性在设计中固定。
- [ ] 真实 200 周核对一致，构建不写 data/；桌面及窄屏可读，图线不单靠颜色区分。
- [ ] --local、云端失败横幅、四川/全国多病原/儿童卡片契约不回归。
