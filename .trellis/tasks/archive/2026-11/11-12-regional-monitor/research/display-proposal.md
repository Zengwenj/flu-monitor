## 2. 信息架构：地区导航与片区导航是两个语义层

这是本方案最关键的区分：

- **地区**（我住哪/要看哪）：成都、黑龙江、重庆——回答"某个具体地方的情况"。
- **片区**（大区域背景）：南方片、北方片——回答"该地方所在大区域的整体走向"。

成都是**地区**，不是南方片的入口。南方片必须有自己对称的页面，北方片同理；否则"南/北片切换"实际退化成"成都 vs 北方"，与需求不符。

### 推荐方案（静态多页，相对链接）

```
site/
├── index.html          成都（地区，默认首页，现有内容保留）
├── heilongjiang.html   黑龙江（地区）
├── chongqing.html      重庆（地区）
├── south.html          南方片（片区，新增）
└── north.html          北方片（片区，新增）
```

导航分两组，语义与间距都分开：

```html
<nav class="sitenav" aria-label="地区">
  <a href="index.html" ...>成都</a>
  <a href="heilongjiang.html" ...>黑龙江</a>
  <a href="chongqing.html" ...>重庆</a>
</nav>
<nav class="sitenav sitenav-zone" aria-label="片区（区域背景）">
  <a href="south.html" ...>南方片</a>
  <a href="north.html" ...>北方片</a>
</nav>
```

- 成都页保留全部现有卡片（含 A1b 历史卡），并在南方片相关卡片旁提供"查看南方片页"链接，**但不把成都页标题或定位写成"南方片"**。
- 南方片页承载同一批南方片证据（流感趋势、A1b 同周对比、南方片前三名称），与成都页共用同一规范化视图与渲染函数，同一 CSV、同一锚周，不产生第二套口径。

### 为什么不合并为单页内切换

现有 `index.html` 是无 JS 的纯生成内联页，单页内"切换"只能靠 `<details>` 折叠，地区归属只能靠折叠面板标题表达，导航语义弱。独立文件的好处是结构性的：

- Python 按页生成，每页口径固定、可独立校验（§8 的地区隔离检查依赖文件边界）。
- 与现有单出口模式一致，只是增加 `OUT_*` 变量，不改动既有渲染函数。

以下**不在本方案中作为依据**（未实测，实施阶段再验）：`file://` 下哈希锚点是否稳定、`<details>` 在移动端浏览器的默认展开行为、单页失败是否影响其他页生成、Pages 子路径分享链接的实际可用性。多页方案只依赖"同目录相对链接"，这是构造上可保证的；浏览器实际行为在实施验收中记录。

### 备选方案

`<details>/<summary>` 单页折叠：零 JS，但地区归属弱、页面很长，仅作为"不得不用单页"时的次选，不作为推荐。

## 3. 导航视觉规格

### 结构与样式

```css
.sitenav {
  display: flex;
  flex-wrap: wrap;              /* 允许换行：宽度不足时换行，绝不截断 */
  gap: 6px;
  padding: 10px 16px 0;
  background: #fff;
}
.sitenav-zone {
  padding-top: 4px;
  border-bottom: 1px solid #e2e6ea;
}
.nav-item {
  font-size: 14px;
  line-height: 1.3;
  padding: 8px 12px;
  border-radius: 6px;
  color: #3a6ea5;
  text-decoration: none;
  white-space: nowrap;
  min-height: 44px;             /* 触屏目标 */
  display: inline-flex;
  align-items: center;
}
.nav-item.active {
  background: #1f2937;
  color: #fff;
  font-weight: 600;
}
.nav-item:focus-visible {
  outline: 2px solid #2f5f8f;
  outline-offset: 2px;
}
```

当前页锚点加 `class="nav-item active"` 与 `aria-current="page"`，不使用 JS。

### 宽度与换行

**不做"单行必然容纳"的承诺。** 两行共 5 项，汉字宽度加 padding 后总宽超过 320px 是正常情况，导航必须换行；换行是设计要求，不是缺陷。要求只有两条：

1. 任一导航项的文字不被截断（`white-space: nowrap` 不配 `overflow:hidden`）。
2. 导航换行后不引起页面级横向滚动（`flex-wrap` + 容器 `max-width` 已保证，验收见 §8）。

对比度数值（如活动项文字/底色）按 sRGB 相对亮度公式估算，仅作为选色依据；实际渲染后的对比度在实施验收中读取，不在本方案里写死为事实。

## 4. 口径标签体系

每张卡的副标题必须显式标注口径层级，禁止省略。

| 口径层级 | 标签文案格式 | 适用数据 |
|---|---|---|
| 全国哨点 | `全国哨点口径 · 非 [地区名] 实测` | 多病原阳性率数值、趋势折线 |
| 片区前三名称 | `[南/北]方片前三名 · 仅列名称，无百分比` | `sentinel_rank.csv` 中 `dimension='region'` 且 `category` 为对应片区 |
| 片区流感数值 | `[南/北]方片哨点 · 国家流感中心` | 流感周报片区 ILI%/指数 |
| 省级官方公告 | `[省名] 官方公告 · [月度/周度] · [来源]` | 省疾控发布内容 |
| 官方来源未结构化 | `官方来源已核实 · 本工具未转成数值` | 有官方页面，但内容未被结构化采集 |
| 地方值未取得 | `[地区名] 当地数值 · 本工具未取得` | 未获取状态占位 |

**绝对禁止**：
- 把全国哨点数值卡改标题为"黑龙江多病原排行"/"重庆多病原排行"。
- 把"北方片前三名称"写成"黑龙江前三病原"，把"南方片前三名称"写成"重庆前三病原"：片区名称不是省份数据。
- 黑龙江、重庆与纯片区页面不得出现四川官方分级（含"IV 级""平原区"等分级结论），也不得以"参考"为名引入；成都页保留既有四川分级。
- 把成都页当南方片总入口（片区组必须有独立"南方片"项）。

## 6. 降级状态定义（六态，按证据区分）

前一版把"没有新行""获取失败""未核实来源"混在一起，任何一个都会被读成"官方还没发布"，这是不允许的。以下每态都有**明确的证据来源**；没有对应证据就只能用"本工具未取得"，不得升级为官方陈述。

| 状态 | 判据（证据） | 展示规则 |
|---|---|---|
| **正常** | 本地 CSV 该周期有 `status=ok` 行，且数值通过校验 | 数值 + 口径标签 + 来源链接 |
| **本次未成功获取** | 本次运行有失败记录或明确跳过记录；`failed` 与 `skipped` 分开解释，不要求向权威 CSV 写失败行 | 有旧值则显示旧值及数据期；失败写“本次获取失败”，跳过写“本次未执行获取”；无旧值写“本工具尚无可用记录”。仅在记录提供时间时显示该时间 |
| **本工具未取得该期** | 无该周期行、也无失败记录（未覆盖/未实现采集） | 显示"—" + 标签"本工具未取得该期（最新收录 YYYY年第W周）"；**不得写"官方尚未发布"** |
| **官方已核实尚未发布** | 仅限官方明确说明本期未发布的可复核证据，须附来源与核实时间；列表未发现新期或惯常发布节奏均不足以证明 | "官方已核实，本期尚未发布" + 证据链接 + 核实时间 |
| **官方来源已核实，但未结构化** | 官方页面存在且可打开，内容为 PDF/图片/非表格，本工具未转成数值 | "官方来源已核实 · 本工具未转成数值" + `<a href>` 外链；不显示 0，不显示推测值 |
| **来源未核实** | 尚未确认该来源是否存在、字段为何（研究未完成） | "本工具未取得 · 来源待核实"；**禁止**与外链态混用（外链态意味着已核实存在） |

**日期差不构成证据**：`today - 上次发布日期 > N 天` 只能触发"数据已逾 N 天未更新，来源可能延迟发布"这类**工具自身陈旧提示**，不得推出"官方尚未发布"，也不得推出"来源出问题"。陈旧阈值按来源发布节奏分别设定，具体数值由数据研究填入（§9），本方案不预设 14 天等具体值。

**插槽 B/C 在来源研究完成前**，默认渲染"来源未核实"态；设计不预设它之后会变成"正常"。

### 320/360px 布局（浏览器实看，`file://`）

- [ ] 320px 与 360px 宽：`document.documentElement.scrollWidth <= clientWidth`（页面级无横向滚动）。两组导航允许换行。
- [ ] 导航项文字无截断（可换行、可多行排列；5 项全部可见可点）。
- [ ] 触屏目标：每项实际高度 ≥ 44 CSS px。
- [ ] 历史卡 `.hist-scroll` 仍只在容器内横滚，不扩大页面宽度。
- [ ] 降级态的"？""—"大字号与说明文字在 320px 可读（不小于正文最小字号），说明文字不被 `nowrap` 撑出容器。
- [ ] 活动项：`aria-current="page"` 存在且视觉可辨（不靠颜色单一通道）。
- [ ] 键盘 Tab 可达所有导航项，焦点可见。

### 零 JS / 零外部依赖

- [ ] 生成物无 `<script`、无 `fetch(`、无 `<img src="http`、无 CSS `url(http`（官方 `<a href>` 外链不计入）。

### 地区归属（人工目视，逐页）
