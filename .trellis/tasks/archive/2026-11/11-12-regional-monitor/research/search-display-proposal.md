# A2 省市搜索展示规格（设计咨询，不实施）

review_kind=design-proposal；mode=advisory。本文取代 `research/display-proposal.md` 的 §2（五页结构）、§3（固定导航）、§5b–§5e（片区页/黑龙江页/重庆页）。该文件 §4（口径标签）、§6（六态）、§8 中的“口径隔离”条目继续有效。以下全部是设计规格，**未做任何实测**。

## 1. 结论与前提

- 默认仍是 `index.html` 成都（四川），保留现有全部卡片和 A1b 历史卡。顶部只增加**一个**“查询其他省市”搜索框；不再有固定的黑龙江、重庆、南方片、北方片导航，也不另建 `south.html`/`north.html` 等页面。
- 查询结果在同页的结果区显示，不跳转，也不改变成都的原内容；“回到成都”一键还原。
- 查询范围：省级（含直辖市）、地级（地级市、自治州、地区、盟）与单独处理的省直辖县级单位。省直辖县级单位不伪造地级父级，候选副行显示所属省级单位与行政类型；不扩展所有区县。
- **与旧约束的冲突**：`src/build_site.py` 文件头写“无 JS”，A1b 及更早验收用 `grep '<script'` 要求为 0。输入搜索无法零 JS。用户已批准**少量内联 JS**（仅用于离线候选、消歧、结果切换），因此：
  - 允许：无 `src` 的内联 `<script>`。
  - 仍禁止：外部脚本、`fetch`/`XMLHttpRequest`/`WebSocket`/动态 `import`、`eval`/`new Function`、运行时联网。
  - 落地时需同步改写 `build_site.py` 文件头与验收 grep 规则；这属于实施阶段的变更，须待成稿评审与用户批准，本文不动。

## 2. 最小离线实现思路（建议，待批准）

1. 构建时把**行政名录**写成一个内联 JSON（`<script type="application/json">`）。字段：`id`、`name`、`short`、`aliases`、`type`（省/直辖市/地级市/自治州/地区/盟及明确纳入的省直辖县级单位）、`province_id`、`direct_under_province`、`flu_region`、`sentinel_region`。两个产品映射分别取 `south`/`north`/`null`；无独立依据一律 `null`。`</` 须转义，避免提前结束脚本。
2. 构建时预生成结果卡片片段，放进 `<template>`：全国卡、南方片卡、北方片卡、黑龙江省卡、重庆官方链接卡、“省级未取得”卡、“市级未取得”占位卡。每个地点按“配方”（卡片片段 id 的有序列表）拼出结果。片段总数是个位数到十几个，**不是每个城市一份**。
3. 脚本只做三件事：按名录过滤候选、选中后克隆对应片段并显示、回到成都。**不在脚本里计算或格式化任何数值**，所有数值与数据期都在构建时由 Python 写好。
4. 用户输入文本只用于匹配，**永远不拼进 HTML**。候选项与“无匹配”提示里回显的文字一律用 `textContent` 写入，回显截断至约 20 字。
5. 匹配逻辑写成纯函数（输入：归一化文本 + 名录；输出：候选数组），便于将来离线单测；是否有 Node 可跑未核实，不作承诺。
6. 脚本初始化成功后才显示搜索框；初始化失败（脚本被禁、名录损坏、运行报错）时不显示搜索框，显示常驻说明行“地区查询需要脚本支持，当前不可用；下方为成都默认内容”，成都内容完整可读。该说明行默认可见，由脚本在初始化成功后隐藏（不依赖 `<noscript>`，以覆盖脚本报错的情况）。
7. v1 **不做地址栏状态**，刷新回到成都；分享链接始终指向成都。若将来要做可分享的查询地址，需先实测 `file://` 与 Pages 下哈希行为，另行批准，本文不预设其可行。

## 3. 交互规格

**控件**
- 可见 `<label>`“查询其他省市”（不能只用 placeholder）；`<input type="search">`；`autocomplete="off"`；`enterkeyhint="search"`；字号不小于 16px（避免部分移动浏览器聚焦即放大，待实测）。
- 旁设“清空”按钮（真实 `<button>`）与“回到成都”按钮；触控高度目标 44px。
- 候选列表采用 ARIA combobox：input 带 `role="combobox"`、`aria-expanded`、`aria-controls`、`aria-autocomplete="list"`、`aria-activedescendant`；列表 `role="listbox"`，项 `role="option"`。另设 `role="status"` 的礼貌播报区，报告“找到 N 个地点”“已显示：某某”“没有匹配”。

**输入与候选**
- 输入法组合期间（`compositionstart` 到 `compositionend`）不过滤，结束后再过滤，避免拼音过程中候选乱跳。
- 归一化：去首尾空白、全角转半角；匹配名称、简称、别名，前缀匹配优先于包含匹配。省/市/自治区/自治州/盟后缀可省略。
- 候选最多 8 条，超出显示“共 N 个，请输入更多字”。
- 每个候选两行：主行是地名，副行是“所属省 · 类型”（例：`吉林市` / `吉林省 · 地级市`）。同名异地必须靠副行区分。已知同名示例（名录由 explorer 核实）：吉林省与吉林市，海南省与海南藏族自治州。
- 不自动替用户选择。只有唯一候选时，Enter 才等同于选中；有多个候选且未高亮时，Enter 只提示“有 N 个相近地点，请从列表中选择”，焦点不动。
- 输入文本本身不能提交。必须选中一个真实名录条目，才切换结果。

**选中、清空与返回**
- 选中后：隐藏成都内容（用 `hidden` 隐藏，不删除），显示结果区；焦点移到结果标题（`tabindex="-1"`），播报“已显示：某某”。
- 选中成都市：回到默认成都页，不重复渲染。选中四川省：显示四川省结果，不自动当作成都市，也不把成都平原区等级当作全省等级。
- 四川省其他地市：当地数据未取得，**不借用平原区等级**（本工具未核实该市属于哪个区域）。
- “清空”只清输入框并收起候选，**不改变**当前结果；“回到成都”才还原默认页，并把焦点移回搜索框。
- 键盘：↓/↑ 移动高亮，Enter 选中，Esc 先收起候选、再按一次清空输入，Tab 收起候选并正常移动焦点（不选中）。

**结果区**
- 标题：“查询：{省}{市}（{类型}）”；紧跟一行说明“本工具暂无该市当地数据；以下为可用参考，各层口径不同”（有当地数据时不显示）。
- 口径概览（`<dl>`，四行，各一行字）：当地 / 省级 / 片区 / 全国，各写状态词。
- 卡片顺序固定：当地（市）→ 省级 → 片区 → 全国。每张卡必须有：层级标签文字（当地/省级/片区/全国，不能只靠颜色）、病种与地理范围、数据期（`YYYY年第W周` 或 `YYYY年M月`，未知写“数据期：未提供”，不留空）、来源链接（`http/https`，`rel="noopener"`）、状态。
- 层级的非颜色区分：文字标签 + 卡左侧竖条线型（省级实线、片区虚线、全国点线、当地占位细虚线）。颜色起点（按相对亮度公式计算，**非渲染实测**）：`#3b4cb8` 在白底约 7.2:1，`#475569` 在 `#eceff3` 底约 6.6:1；实施后再实测。
- “当地（市）未取得”是一条紧凑占位行：显示“—”，**不显示 0，不放大字号**，不占整张卡高度。

## 4. 查询对象与结果组成

| 查询对象 | 当地（市） | 省级 | 片区 | 全国 |
|---|---|---|---|---|
| 成都市 | 回默认页（现有全部卡） | 默认页已有 | 默认页已有南方片 | 默认页已有 |
| 四川省 | 省级结果；不自动回成都 | 四川省口径，不套成都分级 | 仅在 `flu_region`/`sentinel_region` 分别有依据时显示 | 全国卡 |
| 四川省其他地市 | 未取得；不借平原区等级 | 不显示等级，注明“官方分级按区域发布，成都=平原区，本市所属区域未核实”，附回成都入口 | `flu_region`/`sentinel_region` 分别有依据时显示 | 全国卡 |
| 黑龙江省 | 本身即省级 | 黑龙江省卡，仅省级数据；字段以 `design.md` 已核内容为准 | 北方片 | 全国卡 |
| 黑龙江省地级市 | 未取得 | 黑龙江省卡，卡内标“省级，非该市” | 北方片 | 全国卡 |
| 重庆市 | 本身即省级 | 仅官方入口卡：只链接，不转载正文、数值、图片 | 南方片（`zone` 有依据时） | 全国卡 |
| 其他省 / 直辖市 | 本身即省级 | “本工具未取得”或“来源未核实”（见 §5） | 两个产品分别有依据才显示对应片区卡 | 全国卡 |
| 其他省的地级市 | 未取得 | 同所属省 | 同所属省 | 全国卡 |
| 名录未收录（区县等） | — | — | — | 无匹配页，见 §5 |

硬性规则：
- 黑龙江页与重庆结果中**任何位置**都不得出现四川等级。
- 片区卡只引用名称与已有片区数据，标题写“北方片”或“南方片”，不得改写成省名。
- 全国数值卡标题保持“全国哨点”，不得换成地方标题。
- 没有可靠南北映射时，只显示全国卡与已核实的省级卡，并在概览里写“片区：本工具未核实该省所属片区”。

## 5. 状态表

| 状态 | 触发 | 用户所见 | 禁止 |
|---|---|---|---|
| 默认成都 | 加载完成 / 回到成都 | 成都全部卡 + 搜索框 | — |
| 脚本不可用 | 脚本被禁、报错、名录加载失败 | 成都全部卡 + 说明行“地区查询需要脚本支持，当前不可用”，无搜索框 | 显示不可用的空输入框 |
| 输入中有候选 | 过滤出 1–8 条 | 候选列表 + 播报条数 | 自动选中 |
| 候选过多 | 超过 8 条 | 前 8 条 + “共 N 个，请输入更多字” | 静默截断 |
| 同名需选择 | 多条同名或相近 | 候选副行带所属省与类型 | 默认选第一个 |
| **无匹配** | 名录中没有该文字 | “名录未收录‘…’（首版支持省、直辖市、地级市、自治州、盟，区县暂不支持）” | 与“无当地数据”混用；写成“暂无数据” |
| **已选·当地数据未取得** | 名录有此地，无当地数据 | “{市}当地数据：本工具未取得”+ 可用参考卡 | 写成“暂无该地疫情”“安全” |
| 已选·仅官方链接 | 重庆 | 官方入口卡（外链），明示本工具未转成数值 | 转载页面文字、数值、图片 |
| 已选·省级来源未核实 | 该省来源未核实 | “省级：本工具未取得 · 来源待核实” | 与“官方来源已核实、未转成数值”混用 |
| 已选·无片区映射 | `zone` 为空 | 只显示全国卡与已核省级卡 | 猜测所属片区 |
| 已选·数据期过旧 | 卡内数据期落后 | 卡内显示数据期与“数据已逾 N 天未更新”（阈值待数据研究） | 把日期差写成“官方未发布” |

卡内数据状态沿用 `display-proposal.md` §6 的六态（正常 / 本次获取失败显示旧期 / 本工具未取得该期 / 官方已核实尚未发布（须附证据）/ 官方来源已核实但未结构化 / 来源未核实）。

## 6. 验收清单（均未执行，需实施后逐项实看）

**A. 生成物静态检查（不需浏览器）**
- [ ] 无 `<script src`、无 `fetch(`、`XMLHttpRequest`、`WebSocket`、`import(`、`eval(`、`new Function`；脚本内无 `http://`、`https://`。
- [ ] 脚本中没有对用户输入使用 `innerHTML`、`outerHTML`、`insertAdjacentHTML`、`document.write`。
- [ ] 内联 JSON 中 `</` 已转义；JSON 可被解析；每条记录的 `zone` 为 `south`/`north`/`null`。
- [ ] 黑龙江、重庆的结果片段中不含“平原区”“四川官方流感分级”“IV 级”“V 级”。
- [ ] 凡出现“尚未发布”的卡，同卡内有证据来源与核实时间。
- [ ] 每张结果卡带层级标签与数据期（未知写“未提供”）。
- [ ] 默认成都部分与改造前逐项一致（含 A1b 历史卡）。

**B. file:// 双击打开（Chrome / Edge 桌面各一遍；手机端若有条件再测）**
- [ ] 控制台无报错，无网络请求。
- [ ] 输入“哈尔滨”：候选出现，选中后显示黑龙江省卡 + 北方片 + 全国；当地占位写“未取得”；页面上无四川等级。
- [ ] 输入“重庆”：只出现官方入口卡，卡内无转载正文、数值、图片。
- [ ] 输入“吉林”：出现吉林省与吉林市两个候选，副行可区分；选中其一后标题正确。
- [ ] 输入名录里没有的文字：显示“无匹配”，且与“当地数据未取得”文案不同。
- [ ] 输入“成都”：回默认页，不重复渲染成都内容。
- [ ] 清空只清输入框；“回到成都”能还原默认页，焦点回到搜索框。
- [ ] 禁用脚本重开：成都内容完整，显示“查询不可用”说明行，无空输入框。
- [ ] 输入内容含 `<b>`、引号、`&` 时，页面只作为文本显示。
- [ ] 使用中文输入法打字（组合期）时候选不乱跳；组合结束后才过滤。

**C. 键盘与读屏（人工）**
- [ ] 仅用键盘可完成：输入 → ↓ 选候选 → Enter → 看结果 → 回到成都；Esc 与 Tab 行为符合 §3。
- [ ] 焦点始终可见；选中后焦点在结果标题上，播报“已显示：某某”。
- [ ] 候选数量与结果切换有礼貌播报；读屏朗读 combobox 与 option 角色正确。

**D. 窄屏与桌面（320 / 360 / 桌面各一次截图）**
- [ ] 320px、360px：`document.documentElement.scrollWidth <= clientWidth`（页面级无横向滚动）。
- [ ] 搜索框与按钮在 320px 可换行排列，不重叠、不截断；输入字号 ≥ 16px。
- [ ] 候选项可换行，副行不被省略号吞掉；列表最大高度约半屏并在内部滚动。
- [ ] 虚拟键盘弹出时，输入框与候选仍可见（真机或模拟器核对）。
- [ ] 所有按钮、候选项触控高度 ≥ 44px；层级标签与说明文字 ≥ 11px。
- [ ] 概览与卡片在 320px 下单列，口径文字不被 `nowrap` 撑出；A1b 同周表仍只在其容器内横滚。
- [ ] 桌面：搜索区、结果标题、卡片宽度与原成都页一致（`max-width` 不变）。

浏览器自动化工具当前不可用，且 A1b 记录显示本机 Python 无 playwright。视觉与键盘验收不能只看 HTML 存在；若无自动化环境，改用浏览器 F12 设备工具栏 320/360 手测并截图，不得声称已通过。

## 7. 待填入与待决定

| 项 | 来源 | 影响 |
|---|---|---|
| 行政名录（名称、类型、所属省、别名、省直辖县级单位） | explorer | 候选与消歧；决定“无匹配”边界 |
| 两个产品的南北片映射及官方依据 | explorer | 分别写入 `flu_region`/`sentinel_region`；无依据即不显示对应片区卡 |
| 北方片流感数值是否获得、历史同周卡是否做 | 数据研究 | 北方片卡形态，与搜索入口独立 |
| 黑龙江省级已核字段 | `design.md` / 数据研究 | 黑龙江省卡内容 |
| 重庆官方入口链接与使用许可 | 已确认，沿用 | 仅链接，不转载 |
| 四川各地市所属五大区域 | 未核实，默认不展示 | 若核实，才可考虑给四川其他地市显示区域等级 |
