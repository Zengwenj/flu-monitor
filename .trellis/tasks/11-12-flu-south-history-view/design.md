## 2. 一次读取与规范化契约

render 内只读一次 FLU_CSV，构造供 flu_block 与新历史卡共用的内存视图。保持 flu_block() 无参可调用（可增加可选模型参数）；其他现有函数签名不变。不引入第三方运行依赖或通用数据框架。

1. 周键解析为整数，用 date.fromisocalendar(year, week, 1) 验证。非法键不参与排序/绘图，保留忽略条数，在南方片数据提示中显示“有N条无效周次记录，未采用”。
2. 按合法周键分组。无 ok 行的周为失败/缺失；存在 ok 时忽略该周失败占位（失败不能盖掉成功）。成功行的指标三元组为 goldstein_index、south_ili_pct、south_flu_positive_pct。
3. 三个值都须可解析且有限、非负；ILI和阳性率≤100，指数≤10000。空白、NaN、Inf、非法字符不转0。数值0有效。展示使用经过验证并HTML转义的原字符串；不重新计算或写回指数。
4. 同周多条成功行：三元组数值相同且全部有效时合并一点；若任一成功行无效或三元组冲突，整个周标“数据异常，未采用”。不按 fetched_at 选择一个冲突值。相同值元数据用(fetched_at, source_pubdate, source_url, week_start)字符串排序最大的一行，保证输入乱序结果一致；不将此选择解释为版本修订判断。
5. 锚周为合法周键中含 ok 行的最大键，**在指标过滤之前确定**。最新 ok 数值异常时仍保留该锚周，不静默退到更早周冒充最新；当前卡指数显“数据异常，未采用”，环比停止，该年较早有效点仍可绘制。无合法 ok 周时两块为空态，不借失败行造数据。
6. 元数据不决定指标是否有效。周起按ISO周一显示（标“ISO周起”）；CSV week_start 与计算值不一致时在该行注“原周起标注不一致，按ISO周序对齐”。日期/来源字段缺失明确写“未提供”。source_url 仅允许 http/https 且有主机名；其他值不生成链接，显示“来源链接未提供”。所有动态文本与属性用 html.escape，target=_blank 配 rel=noopener。
7. 视图包含各周状态、有效值、原始展示字段、锚周、忽略键数量。新逻辑只读，不写 changes.log；异常说明由页面承担。

## 3. 当前流感卡与环比

- 当前值与同周卡使用同一锚周和规范化结果；旧 yoy 标签直接移除，不在当前卡重复历史判级。
- 精确上一周键由锚周ISO周一减 timedelta(days=7) 再 isocalendar 得到，不查“最近更早一周”，不复用 _adjacent_week。
- 当前及上一周有效指数比较：大/小/等分别“较上周 ↑/↓/→”。用同一规范化记录判断有效性并比较；合法0参与比较。
- 当前指数异常：“较上周：本期数据异常，未比较”；上周无记录或失败：“较上周：上周数据缺失，未比较”；上周异常：“较上周：上周数据异常，未比较”。单点首期也用缺失文案，不承诺下次必有环比。
- 同一南方数据域的状态修正：只对晚于锚周的失败周保留“最新一期获取失败 · 显示上次成功数据（Y年第W周）”横幅；历史失败仅为缺点/内部缺口，不再以 elif fail 误报最新失败。全部失败时显示暂无可用数据并说明存在未成功记录。数据异常不能挂“数据正常”。正常值标签加数据年份，避免旧年看成今年。
- run_banner(local=...) 完全保持原样：云端运行失败仍有独立横幅；本地仍忽略 run_status.json。此任务不新增日历过期阈值，始终明确数据年周和来源发布日期。

## 4. 历史卡数据选择

- 标题“南方片流感指数 · 历年同周对比”。锚年Y及Y-1、Y-2、Y-3中至少一有效点的年份入图；锚年即使最新周异常也保留表格行。有部分历史就展示，不要求全年完整，不越过缺年补更早年。
- 推荐历史全年，本年度只到锚周；当前以“数据年度”称呼，不以日历“本周”称呼。未来区浅灰底，注明“灰底为数据年度尚无观测的周次；往年走势仅供对照，不是预测”。该可逆展示选择包含在整份计划的用户批准内。
- 按年独立分线，周序横轴1–53。同年相邻整数周差1才连线；缺失/异常处断线、单点独立可见；不跨年连接，不插值、不补零、不外推。
- 覆盖N为入图有效周数，内部缺K=set(range(first,last+1))-有效周集合，仅统计首末有效周之间，不将未覆盖年初或未来周算缺口。每行标“已收录N周”，K>0再标“内部缺K周”。不使用当前机器日期计算覆盖。
- 表格按Y降序，对齐锚周W：有值显示指标；该年ISO不存在W53显示“该年无第53周”；周缺失/失败显示“该周缺失”；冲突/非法值显示“数据异常，未采用”。只在实际缺失单元格显示文字，合法0不抹去。
- 仅一年度：保留图表及表，说明“仅收录Y年数据，暂无可对比的往年同周数据”；若有历史曲线但锚周无历史有效观测，说明“往年该周暂无可用观测”。无有效点不画坐标，显示“暂无可用的南方片历史数据”；有锚周异常仍说明锚周及异常，不误称等待回补。

## 5. 视觉规格（designer负责）

### 图与坐标

内联SVG viewBox=0 0 280 192，width:100%、max-width:280px、height:auto，左对齐；边距左26/右10/上16/下26，绘图区244×150。轴字12 SVG单位；在320px屏预期约11px，实际截图验收。X刻度1/14/27/40/53，首左末右对齐；图外解释“刻度约对应1月初、4月初、7月初、10月初、年末”。

纵轴统一线性从0起，不归一化，不用对数。target=max(10,maxval*1.06)；按升序遍历step∈{1,2,5}×10^k（k从0起），取首个ceil(target/step)≤5；n=ceil(target/step)，top=n*step。标0与top，内部step至(n-1)*step画网格。真实max604.84→step200/top800/内部网格200,400,600；全零→step2/top10。Y映射夹在17至165防描边裁切，不将值改变为1；表格保留真实0。横轴周映射固定，缺点不压缩间距。

锚周竖虚线及“第W周”文字；W靠右时文字右对齐向内、靠左时左对齐，不越界。灰底只在W<53时画。图例及标记先历史后锚年，避免近似值遮挡。

### 表与窄屏

六列：年份（线样/已收录N周）｜ISO周起｜指数｜ILI%｜阳性率%｜来源。数值正文保留原字符串，百分号由表头定义。caption明确数据锚年周与发布日及“按ISO周序对齐，周起日逐年略有错位”；th scope=col。每个同周有效行可链接当期官方文章，无JS。

新卡使用局部CSS类，TPL内双花括号。表包在唯一横向滚动容器，width/max-width100%、overflow-x:auto，表min-width340px、单元格nowrap；页面/卡片不增加overflow掩盖问题。≤420px提示“↔ 左右滑动查看完整对照”。容器可键盘聚焦，有可访问名称；320/360px只允许表容器横滚，页面不溢出。图不横滚。表正文至少12 CSS px，辅助说明至少11 CSS px。不以CSS行数作为质量门。

### 文案与来源

标明南方片、国家流感中心《中国流感监测周报》、Goldstein相对强度、实际年度集合、数据年周、来源发布日期。无来源的单元格不能空白冒充正常。说明非感染概率/风险等级/百分位；不自动输出偏高偏低、名次或安全结论。真实200周输入清除旧“约150期/待历史回补/暂无往年同期数据”占位，异常夹具允许诚实空态。
