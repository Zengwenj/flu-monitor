# PRD：指数与风险等级计算（子任务 2/4）

依赖：data-fetch（读其产出的 data/*.csv）。下游：build-site。

## 要做什么

- 计算南方片 **Goldstein 指数 = ILI%(数值) × 流感阳性率(数值)**（两源均来自国家流感中心南方片周报），逐周序列。保留 89.1 形式，标注为**相对强度指数**（单位辨析见 CONTEXT 术语表，不解释为"每百人 X 人"）。
- **同期对比（D17）**：本年度指数曲线叠加前几年同周曲线，供目视比较；**不计算百分位风险等级**（历史点太少、不稳）。
- **环比箭头（D17）**：各病原/指数的 ↑/→/↓ **仅表示较上周变化方向**（用哨点周报表1原生"较上周"差值）；"高于/低于往年同期"用独立曲线或文字，与箭头分离。
- 多病原活跃度：全国哨点各病原（表1）本周阳性率与较上周方向（标注"全国口径"）。
- 儿童提示：表3 的 0-4 岁、5-14 岁前三名病原（标注"全国哨点儿童病例组、排序非数值、非成都榜"）。
- 四川官方分级：消费 data-fetch 的双通道识别结果；含"待人工确认/过期"状态。
- 输出必须标记每个结论的来源与口径（官方 vs 工具推算、全国 vs 南方片、数值 vs 排序、周 vs 月）。

## 约束

- **不合成"成都综合风险总分"**（D14）；各结论分块、各自可追溯。
- 不把工具推算冒充官方结论；不把"未进前三"解释为"安全/不存在"。
- 阳性率变化用"增加 N 个百分点"，不含糊写"增加 N%"。
- 南方片历史基线必须同地区同口径（国家流感中心南方片历史），**不拿全国 FluNet 阳性率混算**。
- 指数口径遵循 WHO PISA（Goldstein index），附口径说明。

## 验收标准（可独立验证）

- [ ] 给定一周已知 ILI% 和阳性率，指数与手算一致（4.6×19.37=89.1），且界面标注其为相对强度指数。
- [ ] 箭头只反映较上周方向；用"降但仍高于往年"的构造样本验证箭头=↓而同期标注=偏高，二者不矛盾。
- [ ] 同期对比为曲线/文字，无"历史百分位风险等级"输出。
- [ ] 缺历史的早期周次标"无往年数据"而非报错。
- [ ] 多病原/儿童输出均带"全国口径/排序非数值"标注。
