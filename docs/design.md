# 设计方案：传染病数据监测工具（成都 · 自用+可分享）

> 本文档是 grill（第 1–5 轮，2026-11-06）收敛后的完整设计共识。术语见 [CONTEXT.md](../CONTEXT.md)，部署形态理由见 [ADR-0001](adr/0001-github-actions-dual-trigger.md)。

## 1. 它到底是个什么东西（给无开发背景的你）

一句话：**一个会自己每周更新的网页**。
- 托管在 GitHub 的免费服务器上，有一个固定链接，你和家人随时打开看。
- 每周五，GitHub 的机器自动去疾控和 WHO 网站抓最新一周数据、算好指数、刷新这个网页。你不用开电脑、不用点任何东西。
- 你也能在自己电脑上双击一下，立刻生成一份一模一样的本地报告（备用 / 想马上看最新）。

你需要亲自做的事，全程只有三件：① 看网页；②（可选）想立刻更新时双击本地脚本；③ 极偶尔官方延迟发布时，去 GitHub 页面点一下"手动运行"。代码、部署、定时，全部我来。

## 2. 首屏你会看到什么（演进式，先简后繁）

**第一阶段（验证管线）**：一个极简结论页
```
┌─────────────────────────────┐
│  成都 · 本周呼吸道风险        │
│                             │
│     中等  ↑                 │   ← 官方四川流感指数平原区等级(底色) + 南方片周度指数(箭头)
│                             │
│  建议：外出戴口罩，儿童避免    │
│  前往人群密集场所            │
│                             │
│  数据：南方片第44周 / 四川10月 │   ← 口径标注，诚实
└─────────────────────────────┘
```
**第二阶段（仪表盘）**：上面的风险卡 + 流感/新冠/RSV 三条趋势小图（含往年同期对比线）+ 多病原活跃度排行 + 可切换查询其他省市。

## 3. 数据从哪来、怎么拼（核心逻辑）

| 层 | 数据源 | 取什么 | 频率 | 角色 |
|---|---|---|---|---|
| 基础 | WHO FluNet CSV | 中国流感送检数/阳性数 | 周 | 自动化骨干，一次拉全量历史 |
| 基础 | 中疾控哨点周报 | 南方片 11 病原阳性率、ILI/SARI | 周 | 多病原主轴（流感/新冠/RSV 首期上，架构留全 11 种） |
| 基础 | 国家流感中心流感周报 | 南方片 ILI%、流感阳性率、亚型 | 周 | **Goldstein 指数 = ILI% × 阳性率** |
| 本地化 | 四川省疾控流感指数 | 平原区（成都）五级分级 | 月 | 风险等级**底色**（官方权威） |
| 本地化 | 四川省疾控月度法定传染病 | 流感月发病数 | 月 | 省级基线校验 |
| 补充 | 国家疾控局月报 / CHINET / 其他省周报 | 乙丙类 / 细菌 / 外省 | 月-半年 | 后续模块 |

**成都风险等级合成规则（D5）**：
- 底色 = 四川流感指数平原区当月等级（V 低 → 高，映射绿/黄/橙/红）
- 箭头 = 南方片本周 Goldstein 指数 vs 前 3 年同期百分位（↑高于/→接近/↓低于）
- 界面必须分别标注"官方结论（月）"与"工具推算（周）"，不混为"成都实时"。

## 5. 每周自动化流程

```
周五 UTC 定时触发（或手动/本地双击）
  → 抓 FluNet CSV + 哨点周报 + 流感周报（含失败重试、官方未更新则跳过并记录）
  → 解析 → 追加到 data/*.csv（增量，去重）
  → 计算 Goldstein 指数、风险等级、同期对比
  → build_site.py 生成 site/ 下网页
  → git commit + push → GitHub Pages 自动发布
```

## 6. 已知风险与诚实边界

- **成都无真实市级/周度数据**：首屏"成都风险"是南方片周度 + 四川省月度 + 平原区分级的近似拼合，非成都市实测值。此为数据现实，界面如实标注。
- **源可能停更/改版**：广东周报已疑似季节性停更、北京周报 2023 年后停发——抓取需对"某源失效"容错，不让整个管线崩。
- **哨点周报无历史归档**：必须尽早一次性回补约 100 期，晚一周缺一周。
- **抓取稳定性未压测**：chinacdc.cn 深层反爬、WHO 限流未验证，实现时首跑验证。

3. 偶尔：想立刻更新时双击 `run_local.bat`；官方延迟时去 GitHub 点"手动运行"。
