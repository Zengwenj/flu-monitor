# 设计方案：传染病数据监测工具（成都 · 自用+可分享）

> 本文档是 grill（第 1–5 轮，2026-11-06）收敛后的完整设计共识。术语见 [CONTEXT.md](../CONTEXT.md)，部署形态理由见 [ADR-0001](adr/0001-github-actions-dual-trigger.md)。

## 1. 它到底是个什么东西（给无开发背景的你）

一句话：**一个会自己每周更新的网页**。
- 托管在 GitHub 的免费服务器上，有一个固定链接，你和家人随时打开看。
- 每周五，GitHub 的机器自动去疾控和 WHO 网站抓最新一周数据、算好指数、刷新这个网页。你不用开电脑、不用点任何东西。
- 你也能在自己电脑上双击一下，立刻生成一份一模一样的本地报告（备用 / 想马上看最新）。

你需要亲自做的事，全程只有三件：① 看网页；②（可选）想立刻更新时双击本地脚本；③ 极偶尔官方延迟发布时，去 GitHub 页面点一下"手动运行"。代码、部署、定时，全部我来。

## 2. 首屏你会看到什么（演进式，先简后繁）

> 2026-11-06 评审修订（D14）：取消"成都综合风险总分"。首屏是**分块证据页**——不把多源数据合成一个红黄绿总分，而是分块并列、各自标口径。仍结论优先（一眼知道近期该不该防护），但不制造数据支撑不起的精确风险值。

**第一阶段（验证管线）**：极简分块证据页
```
┌───────────────────────────────────────┐
│  成都 · 呼吸道防护参考                   │
│                                        │
│  [四川官方]  平原区流感分级：III 级      │
│            来源:四川疾控 10月 · 月度/区域 │  ← 缺/过期则显示"待更新"，不默认绿
│                                        │
```

**第二阶段（仪表盘）**：各块展开为趋势图（本年度曲线 + 往年同期对比线）+ 全 11 病原表 + 可切换查询其他省市。

## 3. 数据从哪来、怎么拼（核心逻辑）

> 2026-11-06 评审修订（D15）：对齐官方数据真实边界——哨点周报表1只有**全国**阳性率数值，南北/年龄只有前三名排序。

| 层 | 数据源 | 取什么（修订后） | 频率 | 角色 |
|---|---|---|---|---|
| 基础 | 国家流感中心流感周报 | **南方片** ILI%、流感阳性率、亚型 | 周 | **Goldstein 指数 = ILI% × 阳性率**（南方片） |
| 基础 | 中疾控哨点周报 表1 | **全国** 11 病原阳性率 + 较上周 | 周 | 多病原趋势（新冠/RSV/鼻病毒…，全国口径） |
| 基础 | 中疾控哨点周报 表2/表3 | 南北片前三名、各年龄组前三名（**名称非数值**） | 周 | 区域差异 + 儿童分龄提示 |
| 基础 | WHO FluNet CSV | 中国流感国家级送检/阳性 | 周 | 全国背景 + 补充核对（**不替代南方片指数输入**） |
| 本地化 | 四川省疾控流感指数 | 平原区（成都）五级分级（**本地月度半自动**：OCR+多模态识别+用户确认，D19） | 月 | 四川官方分级块（注明月度/区域/时效） |
| 本地化 | 四川省疾控月度法定传染病 | 流感月发病数 | 月 | 省级基线校验 |
| 补充 | 国家疾控局月报 / CHINET / 其他省周报 | 乙丙类 / 细菌 / 外省 | 月-半年 | 后续模块 |

**成都页合成规则（D14/D17 修订）**：
- **不**合成单一总分。各块独立呈现，各标口径。
- 四川官方分级：OCR+多模态双通道一致才采信；缺/过期标"待更新"，不默认绿、不用工具推算顶替。
- 南方片流感：环比箭头仅表"较上周"；往年同期高低用独立曲线/文字，不做百分位等级。
- 全国多病原、儿童排序：显式标注"数值为全国哨点、排序为南方片/儿童组"，不合成"南方儿童排序"，不把"未进前三"说成"安全"。

## 5. 每周自动化流程

```
周五 UTC 定时触发（或手动/本地双击）
  → 抓 FluNet CSV + 哨点周报 + 流感周报（含失败重试、官方未更新则跳过并记录）
  → 解析 → 追加到 data/*.csv（增量，去重）
  → 计算 Goldstein 指数、风险等级、同期对比
  → build_site.py 生成 site/ 下网页
  → git commit + push → GitHub Pages 自动发布
```

## 6. 已知风险与诚实边界

- **成都无真实市级/周度数据**：首屏各块是南方片周度 + 四川省月度 + 全国哨点的拼合，非成都市实测值。此为数据现实，界面分块标注、不合成总分。
- **源可能停更/改版**：广东周报已疑似季节性停更、北京周报 2023 年后停发——抓取需对"某源失效"容错，并在页面显著位置提示数据停更/过期（不让旧数据伪装成最新）。
- **哨点周报有历史归档（2026-11-06 更正）**：实测官网列表页保留至 2024 年第 46 周（开办期）的历史条目，此前"无归档、晚一周永久缺一周"的说法不成立。但不等于每期全文都可访问，回补时须逐期盘点并记缺口。
- **双端写冲突 + 本地 file:// 打开 + Pages 发布（2026-11-06 工程修订）**：① 云端维护发布用主数据，本地默认写独立缓存/输出目录、不自动推送，避免 git 同步冲突；② 本地 HTML 把数据内联进页面（非 fetch 外部 JSON），保证离线双击可打开；③ Pages 用自定义 Actions 构建+上传产物+部署（`actions/upload-pages-artifact` + `actions/deploy-pages`），不依赖"机器人提交自动触发构建"（实测 GITHUB_TOKEN 提交不触发 Pages 构建；分支发布目录仅限根或 /docs）。
- **"近零运维"的现实含义**：正常自动运行、异常有清晰提示和恢复办法，不是"永远不用管"。
- **抓取稳定性未压测**：chinacdc.cn 深层反爬、WHO 限流、GitHub 境外 runner 对 chinacdc.cn 的连通性均未验证，data-fetch 前置验证阶段首跑确认；回补加礼貌限速。

## 7. 你需要做的操作（全清单）

1. 一次性：本地装 Python（我带你，约 5 分钟）——本地即时查看和四川月度识别需要；周度数据的云端自动更新不依赖它。
2. 日常：打开网页看。
3. **每月一次**：双击 `update_sichuan.bat`，它抓当月四川流感指数图片、识别出等级，你瞄一眼确认后它自动写入并推送（D19 半自动，云端不碰多模态模型）。
4. 偶尔：想立刻看最新时双击 `run_local.bat`；官方延迟发布时去 GitHub 点"手动运行"。

仅此而已。
