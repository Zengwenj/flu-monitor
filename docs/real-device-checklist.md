# 真机验收清单（搜索页 + 界面主题）

> 自动化断言已覆盖 aria 标签 / 44px 触控高度 / 320–360px 窄屏 / WCAG 对比度，
> 但从未在实体设备上人工验过。本清单给非开发者使用，预计 10 分钟。
> 做完把结果（哪步过/不过、什么手机）告诉 AI 会话即可，不必自己改任何东西。

## A. 手机窄屏（必做，Android 或 iPhone 任一台）

1. 手机浏览器打开：https://zengwenj.github.io/flu-monitor/
2. **竖屏**从头滑到尾：整页单列、没有文字被屏幕右边缘切掉、
   「历年同周对比」表格可以左右滑动、底部没有横向滚动条。
3. 点搜索框 → 用**拼音九键/全键**输入 changchun 选出「长春」→ 候选列表出现。
4. 依次试三个别名：`蓉城`（应出成都市）、`冰城`（应出哈尔滨市）、
   `春城`（应出**两条**：昆明市 + 长春市，点哪条进哪条）。
5. 任选一条候选 → 显示查询结果 → 点「回成都」→ 页面恢复成都首页。
6. 点「清空」→ 输入框清空、刚才的结果**保持不变**。

**通过标准**：6 步全部完成。任何一步文字截断/点不动/结果不对 = 不通过，记下步骤号。

## B. 触屏手感（与 A 同机完成）

1. 搜索框、三个按钮（查询/清空/回成都）、候选列表每一行：
   用拇指点，**不出现"点不到/点错行"**。
2. 表格行有淡色底纹，滑动时不跟手乱跳。

## C. 读屏（选做，家里有老人用读屏才需要）

- iPhone：设置 → 辅助功能 → VoiceOver 打开；Android：设置 → 无障碍 → TalkBack 打开。
1. 单指右滑逐项浏览：每个卡片标题（如「四川官方流感分级」）都能被朗读。
2. 搜索框能读出用途（不是只读"编辑框"）。
3. 候选列表逐条可朗读，双击选中一条。
4. 等级徽章（如「Ⅳ级 · 活跃期」）能读出文字。

## D. 电脑窄窗口（选做，1 分钟）

浏览器窗口拖窄到大约手机宽度：布局自动变单列，与手机一致。
